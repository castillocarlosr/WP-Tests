ELISA SYSTEMS HOMEPAGE REDESIGN — WEB DESIGNER HANDOFF
=======================================================

HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the complete ZIP file.
2. Keep index.html, styles.css, script.js, and the assets folder together.
3. Double-click index.html to open the website in Chrome, Edge, Firefox, or Safari.

No installation, build command, or local web server is required for previewing
the design. The test-kit search, filters, mobile navigation, animations, and
quote dialog run directly in the browser.

PACKAGE STRUCTURE
-----------------
index.html                         Main homepage
styles.css                         Responsive styling
script.js                          Search, filters, navigation, and dialog behavior
assets/allergen-cutouts.png        Transparent test-kit food imagery
assets/allergen-grid.png           Original supporting food image sheet
README.txt                         This handoff guide

PORTABILITY
-----------
All functional website files and product imagery use relative paths, allowing
the folder to be moved to another Windows or Mac computer without changing the
code. Google Fonts load when internet access is available; standard system-font
fallbacks are used when offline. Links to the existing ELISA Systems website
and email links naturally require internet/email access.

IMPLEMENTATION NOTES
--------------------
- The package is a front-end redesign prototype using HTML, CSS, and vanilla
  JavaScript.
- It can be implemented as a custom site or translated into WordPress/Elementor.
- Before production launch, confirm product names, product codes, URLs, contact
  information, and all technical statements against official documentation.
- Replace or license concept imagery as required by the final production team.
- Connect the demonstration quote form to the approved CRM, email, or form
  processing workflow.
